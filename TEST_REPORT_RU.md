## Что проверялось в интерфейсе

Английский при первом открытии независимо от языка браузера; EN/RU для кнопок,
подсказок, графиков, пояснений и ошибок; сохранение всех параметров и численных
результатов при смене языка. Выполненные испытания Монте-Карло не пересчитываются
и не исчезают от переключения языка. При изменении параметров старые испытания
сбрасываются, как и должны.

Две кнопки во введении загружают нужные опыты. Проверены готовые сценарии,
все направления чтения, пять входных состояний, экспорт и импорт, большое k,
неверный ввод и повреждённый JSON. Импорт не меняет текущий язык. В JSON
сохраняются стабильные ключи и английские описания; числовые значения не зависят
от языка. CSV использует десятичную точку.

Три вкладки проверены в обоих языках при ширинах 320, 390, 768, 1280 и 1440 px.
Горизонтального переполнения всей страницы нет; широкие таблицы прокручиваются
в собственном контейнере. Необработанных ошибок JavaScript и сетевых запросов
в автономной браузерной проверке не было.

## Ограничение тестовой среды

Доступный управляемый Chromium блокирует переходы на file:// и локальные HTTP-адреса.
Поэтому интерфейс проверялся методом Playwright set_content с полным автономным HTML.
Логика запоминания языка, параметра ?lang= и недоступного хранилища отдельно
проверена в Node с имитацией браузерного окружения. Реальное сохранение языка
при навигации в этой среде не проверено; отказ хранилища в программе обработан.

## Повторить

python build.py
python -m pip install -r requirements-dev.txt
python verify.py

Браузерные тесты требуют Playwright и Chromium:
python tests/browser_i18n.py
python tests/browser_smoke.py

Подробные результаты и журналы — в results/. Новые запуски могут менять дату,
данные о среде, снимки экрана и хеши отчётов. Тесты проверяют реализацию;
они не доказывают научную новизну или преимущество на реальном оборудовании.
