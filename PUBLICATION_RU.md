# Размещение FENIX Lab 1.1 — EN / RU

Пакет предназначен для Gontsarenko/fenix-lab. Подготовлены файлы; этот выпуск
не загружает их на GitHub, не меняет разрешения и не включает Pages.

## Что изменилось

Английский стал основным языком. В шапке есть EN / RU, краткое объяснение
назначения и два практических примера с кнопками запуска. Переведены интерфейс,
графики и подсказки; добавлены английские инструкции и новые тесты.
Математические ядра Python и JavaScript сохранены побайтово.

## Загрузка или обновление

Распакуйте архив. Откройте папку, где непосредственно лежит index.html.
В репозитории выберите Code → Add file → Upload files и перетащите файлы и папки
ИЗНУТРИ распакованной папки. Не загружайте сам ZIP и лишнюю внешнюю папку.
index.html должен лежать в корне рядом с README.md.

Название изменения: Publish FENIX Lab 1.1 — English / Russian.
В новом личном репозитории можно выбрать Commit directly to the main branch.
При обновлении совпадающие файлы заменяются; старые лишние файлы сами не удаляются.

Здесь один актуальный манифест SHA256SUMS.txt. Если ранее был загружен
SHA256SUMS_GITHUB.txt от версии 1.0, удалите его или обозначьте как исторический:
его старые хеши больше не описывают этот выпуск.

## Включение сайта

Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
После успешного развёртывания адрес покажет GitHub. Ожидаемый адрес:
https://gontsarenko.github.io/fenix-lab/

Не считайте сайт опубликованным до успешного развёртывания. Проверки в results/
относятся к локальной сборке, а не к уже работающему GitHub-сайту.
