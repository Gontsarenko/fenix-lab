Added in this calculator

Error model

Readout error: after an ideal measurement, the recorded label flips with probability ε. Calibrated feedback chooses the phase from the mixed conditional state for that recorded label.

CNOT: each ideal gate is followed by an independent X flip on the target qubit only, with probability pg. No other gate errors are included.

Collective protocol: its total probability of reporting the wrong parity, q, is specified separately. It is not inferred from ε.

Feedback phase: one independent δ ∼ N(0, σ²) after correction. The mean coherence is multiplied by exp(−σ²/2).

These are explicit modelling assumptions. A strategy’s advantage is an advantage within this model, not on every device.

Reading the metrics

V: interference contrast, 2|ρ01|. It can be zero even for a perfectly preserved |0⟩ state.

F: squared fidelity between the input and output density matrices. F = 1 means the states match.

K: path-guessing advantage. Pguess = (1 + K)/2. A 50% success rate means a random guess, not half a bit.

χ: path information in bits for CZ fragments. For input |+⟩, the total mutual information I(S:E) = 1 + χN also includes phase correlations.

C: the coherence-retention factor in the second mode. Vout = C Vin within the stated error range.

Scope & reproducibility

No energy relaxation, particle loss, leakage, correlated errors, unknown coupling phases, internal environment dynamics, operation durations or hardware calibration are modelled.

Recovery keeps every outcome. The code adds density matrices after applying the actual correction; the sum of coherence magnitudes is used only to check the optimum.

Interface: N ≤ 2,000; API: N ≤ 100,000. Large-N calculations use an exact reduced channel, not the full exponentially sized state.

The project includes a Python core, independent density-matrix tests, Python/JavaScript comparisons, documentation and test results. Random tests do not replace an analytic proof.

The calculator sends no data over the network, connects to no hardware and requires no API keys. JSON and CSV exports are saved locally.
